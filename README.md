# 🎲 Dice Roller

A simple and interactive Dice Roller web application built using **HTML**, **CSS**, and **JavaScript**. Users can enter the number of dice they want to roll, and the application generates random dice values along with their corresponding images.


## 🚀 Features

- 🎲 Roll one or multiple dice
- 🔢 Generates random numbers from **1 to 6**
- 🖼️ Displays dice images based on the generated values
- ✅ Input validation for invalid or empty values
- 🎨 Simple and responsive user interface



## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 📖 How It Works

1. Enter the number of dice you want to roll.
2. Click the **Roll Dice** button.
3. The application generates random numbers between **1 and 6**.
4. The generated dice values and their corresponding images are displayed on the screen.
